Getting Started
###############

Now that your Gatecoin node is up and running, you can choose from the following tutorials, depending on your Gatecoin use case:

See :doc:`Using Gatecoin on Mainnet <using-gatecoin-on-mainnet/overview>` for getting started to use Gatecoin on the Ethereum mainnet.
The :doc:`Gatecoin Web Interface <the-gatecoin-web-interface/the-gatecoin-web-interface>` is the easiest way to use Gatecoin interactively. 
For programmatic use of Gatecoin, see :doc:`The Gatecoin API Tutorial <gatecoin-api-1/api-tutorial/README>`.
